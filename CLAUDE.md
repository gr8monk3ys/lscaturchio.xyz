# CLAUDE.md

Personal site at https://lscaturchio.xyz: Next.js 16 App Router, React 19, TypeScript, Tailwind. Deployed on Vercel from `main`. Bun is the package manager (`bun.lock` is canonical; `package-lock.json` is gitignored).

## Run and verify

- `bun install --frozen-lockfile`, then `bun run dev`
- `bun run lint` (ESLint + `knip` + retrieval-corpus drift check in CI), `bun run typecheck`, `bun run test:coverage`, `bun run build`, `bun run test:e2e`
- `bun run predeploy` runs all of the above; CI (`.github/workflows/ci.yml`) gates PRs on Lint, Type Check, Test, Build, E2E
- Build needs `DATABASE_URL` (Neon); see `.env.example` for the rest

## Where things live

- `src/app` routes and API handlers, `src/lib` shared logic, `src/components` UI, `src/constants` structured content
- `src/app/blog/<slug>/content.mdx` essays (83); `docs/writing-style.md` is required reading before editing any post
- `public/my-data` retrieval corpus for chat; `blog-*.md` there is generated by `bun run sync-retrieval-corpus`, never hand-edited
- `src/generated/audio-manifest.ts` is generated from the audio store; audio itself is on Vercel Blob, not in git
- `supabase/migrations` SQL history; `scripts/` maintenance tasks, all listed in `package.json`
- `docs/operations.md` for content, audio, database and monitoring procedures

## Gotchas

- Server Components by default; blog metadata helpers stay in `src/lib/blog-data.ts` and `src/lib/getAllBlogs.ts`
- The sitemap is `src/app/sitemap.ts`; do not add a postbuild sitemap script
- Editing an essay without `sync-retrieval-corpus` fails CI's drift check
- The `E2E` job builds and serves the app itself, so it needs the same env as `Build`
